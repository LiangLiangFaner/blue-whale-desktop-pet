# 更新动画素材

1. 从托盘退出桌宠，备份整个 `resources/app/assets/whale/`。
2. 替换动画图集和与其配套的时间线、运动场文件。
3. 重新启动 `蓝色大肥鱼.exe`。

同名图片只有尺寸、格子布局、透明背景、帧数和顺序均一致时才可直接替换。普通 GIF 或 ChatGPT Pets 图集不能直接覆盖。

走路使用 `coordinated-walk.png`，4 列 × 2 行、每格 512px，共八个完整角色姿势；同侧手臂与腿交替反向摆动，左右行走共用并镜像。待机立绘为 `idle-front.png`，揉眼睛为 `rub-eyes.png`。

程序时间线在 `src/renderer/motion.js`，行为触发在 `src/main/behavior.cjs`。`ANIMATION_RATE=.7` 控制动作速度。运动场为 `assets/whale/motion-flow.png` 和 `motion-flow.js`，替换原画后应一起重建，避免沿用不匹配的过渡。

在源码目录安装 Python 及 `numpy`、`opencv-python` 后，可运行 `npm run assets:flow` 重建运动场。可设置 `PET_FLOW_PYTHON` 指定 Python 路径。随后将图集、运动场及修改过的时间线一起复制到运行版的 `resources/app/` 对应目录。

源码与更新：[blue-whale-desktop-pet](https://github.com/LiangLiangFaner/blue-whale-desktop-pet)。普通使用不需要安装开发环境。
