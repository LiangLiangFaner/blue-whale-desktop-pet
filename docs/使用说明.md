# 蓝色大肥鱼 · 免安装文件夹版

完整解压 ZIP 后，双击 `蓝色大肥鱼.exe`。请放在可写入的文件夹中，保留旁边所有运行文件。无需安装 Node.js、Python 或配置 API 密钥。

## 操作

- 单击角色摸摸，双击角色或单击托盘图标打开陪伴面板。
- 按住拖动角色，右键可喂食、选择动作、暂停散步、隐藏或退出。
- 面板可调整大小、鼠标跟随、揉眼睛、停靠和定时互动等。
- `Ctrl+Alt+P` 切换鼠标穿透，也可从托盘菜单恢复。
- 找不到角色时，从托盘右键选择回到屏幕内；大小为 0% 时需在面板恢复大小。
- 退出请用角色或托盘菜单的“退出”，关闭面板只会收起面板。

基础动画和小游戏可离线使用，虚构的 token 口粮不消耗模型额度。聊天需要自行填写服务地址、模型和访问密钥；对话发送给所配置的服务，关闭程序后不保留聊天记录。画面分享、自动观察和开机启动默认关闭。

## 文件与更新

```text
蓝色大肥鱼/
  蓝色大肥鱼.exe
  使用说明.md
  更新动画说明.md
  data/                         首次运行自动生成
  resources/app/assets/whale/    动画图集
  resources/app/src/             程序代码
  locales/、*.dll 等             运行依赖，必须保留
```

运行时设置与加密密钥等保存在 `data/`。分享时不要包含这个目录。更新前退出程序并备份旧目录，再把旧 `data/` 复制到新版本中；换电脑后可能需要重填密钥。移除软件时先关闭手动启用的开机启动、退出程序，再删除整个目录。
